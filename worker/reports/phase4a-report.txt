3. Subrequest count
-------------------
Per run with N pending sessions and D due sessions:
  1 GET meeting_types                           1
  2 GET meeting_skip_dates                      1
  3 POST meeting_sessions upsert (ignore)       0 or 1
  4 GET meeting_sessions                        1
  5 GET audit_logs markers, 100 ids per call    ceil(D / 100)
  6 GET meeting_roster                          1
  7 GET meeting_attendance, 100 ids per call    ceil(N / 100)   (N <= 10 -> 1)
  8 POST meeting_attendance, one array body     1 if any row, else 0
  9 POST audit_logs, one array body             1
Total = 6 + ceil(D/100) + ceil(N/100) + (1 when the sup session is created)
      = 8 for N = 1..10, or 9 when the sup session is also created.
Ceiling stays under 50 until D exceeds about 4,100 due sessions in one tick.

Approved formula holds whenever D <= 100: 6 + 2 * ceil(N / 100) (+1 for sup).
Measured in workerd with D = 150: 9 subrequests, still well under 50.

6. Deviations from the spec
---------------------------
a. One module worker/src/auto-absent.js instead of the spec's two files
   (auto-absent.js + auto-absent-job.js), as this task requested.
b. Writes are batched as the spec's sections 2 and 4 require: one
   meeting_attendance upsert and one audit_logs insert per run. Express does
   one of each per session; steps 17-19 of the spec read per session.
c. The marker read chunks over due sessions D, because the spec's step 11
   reads markers for due ids before the B = 10 cap. With D <= 100 the approved
   formula is exact; above 100 the run spends ceil(D/100) there.
d. The attendance upsert is skipped when the batch has no missing employee
   (Express parity), which saves one subrequest.
e. AUTO_ABSENT_CRON is exported from auto-absent.js, not index.js: the local
   workerd run rejected the bundle with "Incorrect type for map entry
   'AUTO_ABSENT_CRON': the provided value is not of type 'function or
   ExportedHandler'", because every named export of the entry module must be
   a handler or Durable Object class.
f. runAutoAbsentOnce returns { processed: 0 } for an invalid `now` value
   instead of throwing, so a malformed scheduledTime cannot fail every tick.

## Route list (exact paths, as mounted)

1. GET /api/meeting/types — meeting_controller session; reads meeting_types ordered by code asc; builds registerUrl from APP_ORIGIN (trailing slash removed) + /meeting/register?t=<encoded qr_token>; APP_ORIGIN missing -> 500. weekly/type reads that fail -> 500 with the save message.
2. POST /api/meeting/qr/rotate — strict body { code: 'sup' | 'monthly' } else 400 ข้อมูลไม่ถูกต้อง; unknown code value -> 400 ข้อมูลไม่ถูกต้อง; missing type row -> 400 ไม่พบประเภทการประชุม; writes a fresh 64 lowercase-hex qr_token, then audits meeting_qr_rotated (entity meeting_type, entity_id = type id, detail null); responds 200 { ok:true, registerUrl }.
3. PUT /api/meeting/window — strict body { openTime, cutoffTime, code? }; code present and not 'sup' -> 400 แก้ไขได้เฉพาะการประชุมหัวหน้างาน; validateWindow errors -> 400 รูปแบบเวลาไม่ถูกต้อง / เวลาเปิดรับต้องก่อนเวลาปิดรับ; unknown sup row -> 400 ไม่พบประเภทการประชุม; updates default_open_time/default_cutoff_time and audits meeting_window_updated with detail {old:{openTime,cutoffTime}, new:{...}}.
4. GET /api/meeting/monthly-session — monthly type only; missing -> 400 ประเภทการประชุมไม่ถูกต้อง; sessions with session_date >= bangkokToday(), ascending, limit 12, mapped {id, sessionDate, openTime, cutoffTime} (HH:mm or null); read failure -> 500 ไม่สามารถบันทึกได้ กรุณาลองใหม่.
5. PUT /api/meeting/monthly-session — strict body { sessionDate, openTime, cutoffTime }; ^\d{4}-\d{2}-\d{2}$ and real calendar date (UTC round-trip), else 400 ข้อมูลไม่ถูกต้อง; validateWindow; sessionDate < bangkokToday() -> 400 เลือกวันที่ตั้งแต่วันนี้เป็นต้นไป; missing monthly type -> 400 ประเภทการประชุมไม่ถูกต้อง; upsert on conflict (meeting_type_id, session_date) with cycle_key = monthly-<sessionDate>; audits meeting_monthly_session_set (entity meeting_session, detail JSON {sessionDate, openTime, cutoffTime}).

Common: every route sets Cache-Control: no-store and requires a valid meeting_controller hr_session cookie; 401 ไม่ได้เข้าสู่ระบบ without a usable session, 403 ไม่มีสิทธิ์เข้าถึงส่วนนี้ for the wrong role. Timezone logic uses Asia/Bangkok via bangkokToday from register-window.js. No rate limit on controller routes. Logs write only { name, code } from errors; no bodies, tokens, hashes or secrets are logged or returned beyond the designed contract (the rotate/types registerUrl carries the token by contract; session cookie values never appear in responses or logs).

Intentional differences (Phase 1 design, not contract mismatches):
- PIN storage: Workers uses HMAC-SHA256(PIN_PEPPER, employeeId + ":" + pin); Express uses bcrypt. Consequence: after this run, EM001's stored pin_hash is an HMAC value, so the Express server's bcrypt comparison will reject that PIN. EM001 can authenticate through the Workers implementation only until Express is migrated or the PIN is reset again via Express.
- Cookie Secure: Workers reads COOKIE_SECURE (false locally only); Express uses NODE_ENV === "production". Production Workers must not set COOKIE_SECURE=false.
- SameSite casing: "Strict" (Workers) vs "strict" (Express); cookie attribute values are case-insensitive.
- Max-Age: 43200 seconds in both.

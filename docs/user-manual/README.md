# ดัชนีคู่มือการใช้งาน HR Hub

คู่มือสำหรับพนักงานโดยตรงอยู่ที่ [คู่มือการใช้งาน.md](คู่มือการใช้งาน.md) ส่วนไฟล์นี้เป็นสารบัญสำหรับเปิดไปยังหัวข้อที่ต้องการ และสรุปว่าผู้ใช้แต่ละประเภทเห็นอะไร

## บทบาทในระบบ

- **พนักงานทั่วไป** — งานของฉันทั้งหมด ได้แก่ ใบลาของฉัน, ยื่นใบลา, ปฏิทินการลา, ข้อมูลส่วนตัว, เปลี่ยน PIN และการแจ้งเตือนใบลา ถ้าได้รับมอบหมายให้เป็นผู้อนุมัติ จะเห็นเมนู งานหัวหน้า เพิ่มขึ้น
- **ผู้ดูแล HR** — ทุกอย่างของพนักงานทั่วไปในองค์กร และเมนู งาน HR ทั้งหมด ใช้ดูใบลาทั้งองค์กร คีย์ใบลาย้อนหลัง ดูแลวันหยุด ผู้อนุมัติ และค่าตั้งต้น
- **หัวหน้าคุมประชุม** — งานประชุม การสร้างรหัสสแกนเข้าประชุม รายชื่อผู้เข้าประชุม สถิติ และข้อมูลย้อนหลัง
- **ผู้ดูแลระบบภาพรวม** — ภาพรวมตัวเลขของระบบ และการกำหนดสิทธิ์ผู้ใช้
- **ผู้อนุมัติ** — ไม่ใช่ประเภทบัญชี แต่เป็นสิทธิ์ที่เพิ่มให้พนักงานบางคน เพื่ออนุมัติหรือไม่อนุมัติใบลาของผู้อื่น

## สารบัญ

1. [ก่อนเริ่มใช้งาน](คู่มือการใช้งาน.md#1-ก่อนเริ่มใช้งาน) — ระบบใช้ทำอะไร ต้องเตรียมอะไร และคุณเป็นผู้ใช้ประเภทไหน
2. [การเข้าสู่ระบบ](คู่มือการใช้งาน.md#2-การเข้าสู่ระบบ) — เข้าสู่ระบบด้วย PIN, ตั้ง PIN ครั้งแรกด้วยรหัส 8 หลัก, เปลี่ยน PIN ก่อนใช้งาน, ลืม PIN, ออกจากระบบ
3. [วิธีเพิ่มแอปไว้หน้าจอหลักของมือถือ](คู่มือการใช้งาน.md#3-วิธีเพิ่มแอปไว้หน้าจอหลักของมือถือ) — ขั้นตอนบน iPhone และ iPad, การใช้บน Android และคอมพิวเตอร์
4. [สำหรับพนักงานทุกคน](คู่มือการใช้งาน.md#4-สำหรับพนักงานทุกคน) — ใบลาของฉัน, ยื่นใบลา, ปฏิทินการลา, ข้อมูลส่วนตัว, การแจ้งเตือนใบลา, อีเมลแจ้งผลใบลา, ใบรับรองแพทย์ของตัวเอง
5. [สำหรับผู้อนุมัติ](คู่มือการใช้งาน.md#5-สำหรับผู้อนุมัติ) — เมนู อนุมัติใบลา และตัวเลข, การอนุมัติ, การไม่อนุมัติ, เมื่อใบลาถูกตัดสินไปแล้ว, อนุมัติจากลิงก์ในอีเมล, ประวัติการอนุมัติ
6. [สำหรับ HR](คู่มือการใช้งาน.md#6-สำหรับ-hr) — หน้าหลัก, รายชื่อพนักงาน, จัดการข้อมูลพนักงาน, นำเข้าพนักงาน, จัดการรหัสผ่านพนักงาน, ใบลาทั้งหมด, คีย์ใบลาย้อนหลัง, วันหยุด, ผู้อนุมัติ, ตั้งค่าใบลา, ส่งลิงก์อนุมัติใหม่, หัวหน้ากะ, ใบรับรองแพทย์, การเก็บข้อมูลใบลา
7. [สำหรับหัวหน้าคุมการประชุม](คู่มือการใช้งาน.md#7-สำหรับหัวหน้าคุมการประชุม) — เมนูและหน้าที่ใช้ในงานประชุม
8. [สำหรับผู้ดูแลระบบ](คู่มือการใช้งาน.md#8-สำหรับผู้ดูแลระบบ) — ภาพรวมผู้ดูแล และสิทธิ์ผู้ใช้
9. [เมนูและการใช้มือถือ](คู่มือการใช้งาน.md#9-เมนูและการใช้มือถือ) — แถบเมนูล่างและปุ่ม เมนู บนมือถือ, เมนูด้านบนบนคอมพิวเตอร์
10. [ปัญหาที่พบบ่อยและวิธีแก้](คู่มือการใช้งาน.md#10-ปัญหาที่พบบ่อยและวิธีแก้) — ลืม PIN, ไม่เห็นการแจ้งเตือน, ตัวเลขรออนุมัติไม่เปลี่ยน, หน้าเว็บค้าง, ไม่เห็นแผนก, เข้าหน้าที่ไม่มีสิทธิ์
11. [ความปลอดภัยสำหรับทุกคน](คู่มือการใช้งาน.md#11-ความปลอดภัยสำหรับทุกคน)
12. [อภิธานศัพท์](คู่มือการใช้งาน.md#12-อภิธานศัพท์)
13. [ติดต่อ HR](คู่มือการใช้งาน.md#13-ติดต่อ-hr)

## ไฟล์อื่นในโฟลเดอร์นี้

- [checklist.md](checklist.md) — รายการข้อความบนหน้าจอทุกข้อที่คู่มืออ้างถึง พร้อมหน้าที่ปรากฏ เพื่อให้ผู้ตรวจเทียบกับระบบได้ทีละบรรทัด

## วิธีใช้คู่มือนี้กับผู้ที่ไม่ถนัดเทคโนโลยี

- อ่านหัวข้อ 1 ถึง 3 ให้จบก่อน แล้วจึงเริ่มใช้ระบบ
- ทำทีละขั้นตามลำดับ อย่าข้ามขั้น และรอให้หน้าจอเปลี่ยนก่อนไปขั้นต่อไป
- ถ้าขึ้นข้อความที่ไม่เข้าใจ ให้เปิดหัวข้อ 10 ก่อนติดต่อฝ่าย HR
- หัวข้อ 13 ต้องเติมชื่อฝ่ายและเบอร์ติดต่อขององค์กรก่อนพิมพ์แจก
